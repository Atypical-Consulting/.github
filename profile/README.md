## Atypical Consulting

Open-source tools for .NET teams and for the AI agents that now work alongside
them. Everything here is MIT, built in the open, and used in production.

### AI tooling

- **[AI Kit](https://github.com/Atypical-Consulting/omarchy-aikit)** — run Claude Code agents on any repository from the [Omarchy](https://omarchy.org/) desktop: pick a repo, pick a skill, and a bar widget tells you when a fleet of agents has landed the PRs.
- **[RoselineMCP](https://github.com/Atypical-Consulting/RoselineMCP)** — Roslyn code intelligence for AI coding agents over MCP. Navigate C# by structure — symbols, references, call graphs, surgical edits — for 81% fewer tokens than reading files.
- **[claude-legends-review](https://github.com/Atypical-Consulting/claude-legends-review)** — AI code reviews by three opinionated personas that debate until consensus.

### .NET libraries

- **[VirtualFileSystem](https://github.com/Atypical-Consulting/VirtualFileSystem)** — test filesystem code without touching the real disk: fast, deterministic, disposable.
- **[Koine](https://github.com/Atypical-Consulting/Koine)** — a DSL for Domain-Driven Design: write your ubiquitous language once, compile it to seven languages plus living docs.
- **[SalesPitch](https://github.com/Atypical-Consulting/SalesPitch)** — a CLI that drafts sales pitches from a framework of your choice.

Issues and pull requests are welcome on every repository.
